# SocialAPIs

> REST APIs for real-time public data from Facebook and Instagram. 200 free API calls / month, no credit card. Trusted by 5,000+ developers and 7.2M+ monthly API calls through the underlying engine.

SocialAPIs is a unified, social-first REST API with flat per-request pricing (~$1.49–$1.63 per 1,000 requests). No bandwidth fees, no compute units, no per-Actor billing. One auth header (`x-api-token`), one rate limit, ~50+ endpoints. First-class MCP server for AI agents (Claude Desktop, ChatGPT Custom Integrations, Cursor).

Live today: Facebook and Instagram. Roadmap (vote on which we build next at <https://socialapis.io/api-sources>): TikTok, X (Twitter), LinkedIn, YouTube.

## API examples

Auth header is `x-api-token` — NOT `Authorization: Bearer`.

Get details of a Facebook page:

```bash
curl "https://api.socialapis.io/facebook/pages/details?link=https%3A%2F%2Fwww.facebook.com%2FEngenSA" \
  -H "x-api-token: YOUR_API_TOKEN"
```

Search Facebook pages by keyword:

```bash
curl "https://api.socialapis.io/facebook/search/pages?query=marketing" \
  -H "x-api-token: YOUR_API_TOKEN"
```

Get Instagram profile details:

```bash
curl "https://api.socialapis.io/instagram/profile/details?username=instagram" \
  -H "x-api-token: YOUR_API_TOKEN"
```
